# IFST (Ivano-Frankivsk Samokat Team) Scooter Archive

This repository contains the source code of a website dedicated to the electric scooters owned and used by the administrators of **IFST (Ivano-Frankivsk Samokat Team)**. The project serves as a community archive where visitors can explore detailed information about each administrator's personal scooter, including technical specifications, modifications, upgrade history, photos, and unique features.

The website also documents the story behind every vehicle, showcasing how each scooter has evolved over time through repairs, customizations, performance upgrades, and everyday use. Every profile aims to preserve the history of the scooter, highlighting important milestones, technical improvements, and memorable moments within the IFST community.

The primary goal of this project is to create a centralized, easy-to-navigate platform that not only presents technical information but also reflects the passion, experience, and creativity of the **IFST (Ivano-Frankivsk Samokat Team)** members. Whether you're interested in electric scooters, custom builds, or simply want to learn more about the vehicles used by the team's administrators, this website provides an organized and informative overview of the entire collection.
